## 📌 Projects

### 1. Polynomial Regression
- Implemented Polynomial Regression to model nonlinear relationships between input features and a target variable.
- Used polynomial feature transformation to capture nonlinear patterns.
- Trained and evaluated the model using a training and testing dataset.
- Compared model performance using evaluation metrics.

**Technologies:** Python, Pandas, NumPy, Scikit-learn, Jupyter Notebook

### 2. Rating Prediction Using Machine Learning
- Developed a machine learning model to predict quality ratings from numerical features.
- Applied data preprocessing and feature selection.
- Trained and compared Linear Regression and Polynomial Regression models.
- Evaluated model performance using R², Mean Absolute Error (MAE), and Root Mean Squared Error (RMSE).
- Tested the trained model on sample inputs to generate predictions.

**Technologies:** Python, Pandas, NumPy, Scikit-learn, Jupyter Notebook
